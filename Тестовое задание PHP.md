## Написать api сервис для обработки данных с форм обратной связи

**Задача:** Реализовать API-сервис для получения и обработки данных с форм обратной связи размещаемых на разных сайтах компании.

В зависимости от полученного набора данных сервис должен определять дальнейшие правила обработки, валидировать и перенаправлять подходящему менеджеру.

Формы могут содержать разные поля, но типовые (при добавлении нового типа формы (набора полей) - заводится новое правило в сервис).

**Точка входа API:**  
Единый адрес для приёма всех форм:  `POST /api/form`

**Правила обработки:**  
Выбирается первый подходящий из указанных сценариев.  
- Поля: имя, email, телефон, профессия, регион, продукт (которым заинтересовался)
    Если выбрана профессия "студент" (`profession` = "студент"), отправить данные на email: `student@example.com`.
- Поля: имя, email, телефон, профессия, регион, продукт (которым заинтересовался)
    Если выбран регион "Санкт-Петербург" или "Москва", отправить данные на email: `center@example.com`.
- Поля: имя, email, телефон, продукт (которым заинтересовался)
    Если выбран продукт "promo" (`product` = "promo"), отправить данные на email: `promo@example.com`.
- Во всех остальных случаях отправить данные на email: `all@example.com`.
    Проверяемые поля: имя, email, телефон, регион, профессия (не обязательное поле)

**Дополнительные условия:**  
- В любом случае, если в форме присутствует поле `address` с указанным email-адресом, данные должны быть отправлены на этот email вместо одного из указанных выше адресов.
- Независимо от выбранного сценария, если выбран продукт "special" (`product` = "special"), добавить дополнительного получателя `special@example.com` к выбранному сценарию.
- Процесс отправки письма не должен блокировать ожидание ответа (выполняться в фоне)

**Формат отправляемого письма:**  
Письмо должно содержать только те поля, которые были переданы в форме и соответствуют указанным выше условиям. Поле "address" в теле письма не передавать.
